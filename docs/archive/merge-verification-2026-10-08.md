This is historical evidence for the implementation before the Rust migration.
It does not verify the Rust CLI, new policy check, credential isolation, or activation preflight.
The workflow pins and test counts below describe that previous implementation.

The scratch checks exposed three runtime adapter defects, fixed in [PR46](https://github.com/civitaspo/securefix-server/pull/46), [PR47](https://github.com/civitaspo/securefix-server/pull/47), and [PR48](https://github.com/civitaspo/securefix-server/pull/48). The pinned github-script action requires `core.summary.addRaw` and the runner's `GITHUB_RUN_ATTEMPT`; the App-token action requires the input `permission-statuses`. The workflow fixture suite has 43 passing tests, including unsigned, missing-signature, empty-list, mismatched-head, and unsigned-parent rejection before write-token readiness. Those tests are separate from the live evidence above.

The temporary Server App probe was restricted to scratch PR7 and removed after its successful run. It reused the existing post-readiness token without exporting credentials or adding a service.

All nine client preparation pull requests are merged. Independent exact-head review confirmed their existing Renovate exclusions were preserved. Their callers and the server caller use the reviewed immutable `0944357ae26c4acf01df9bc37db4be0330566ac2` pin with the matching `v0.2.0-rc.2` annotation. All ten intake workflows are active. The central gate enables production update restrictions after the distribution workflow verifies every caller and confirms no native auto-merge requests remain queued.

Independent security review found no remaining authentication blocker. Replay, wrong-workflow provenance, artifact forgery, and final-head races have fixture coverage; the entire negative matrix has not run against GitHub. Client default-branch workflows and App private keys remain trusted inputs.

Release publication is not a rollout prerequisite: release workflows are unchanged, and merges use a GitHub App token that can trigger subsequent workflows.
